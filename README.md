# ROG魔霸6 Hackintosh OpenCore EFI
### 关于我的EFI，您需要知道：
#### 1.所有操作都在您可控范围内执行，请您备份好重要资料，若出现错误及任何软硬件损坏本人概不负责！
#### 2.请使用EFI后用工具刷写您的三码，或提交给AI帮您处理。

# Bugs
* 随航（核显无法驱动且网卡暂不支持，无法使用）
* AirDrop
* Radeon 680M核显
* 如有更多需要，你可以进行反馈和联系我。

# 注意事项
* 在安装前，您需要到使用奥创中心或G-Helper内切换为混合模式而非独显直连，否则容易卡PCI枚举。
* NVIDIA驱动由nullmoth提供，您需要启动macOS后才能安装，具体可到1401项目查询。
* MT7922网卡驱动由angus666888构建，已接入原生WiFi管理菜单。
* 推荐安装Tahoe，Sequoia‌下网卡驱动暂不支持。
